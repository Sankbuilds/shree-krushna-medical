 # Shree Krushna Medical Website

A responsive medical and pharmacy website developed using HTML, CSS, and JavaScript. The website features a modern UI, enquiry/contact section, service information, and mobile-friendly responsive design.

## 🌐 Live Demo
https://shreekrushnamedical.netlify.app/

## 🚀 Features
- Responsive Design
- Modern UI Layout
- Medical & Pharmacy Information
- Contact / Enquiry Section
- Mobile Friendly Website

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Setup

1. Clone the repository
git clone https://github.com/Sankbuilds/shree-krushna-medical-website.git

2. Open the project folder
3. Run the project using Live Server or open `index.html`
